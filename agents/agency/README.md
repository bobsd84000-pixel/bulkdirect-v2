# Agency Agents x BulkDirect

Agents réels du pack https://github.com/msitarzewski/agency-agents (MIT, copiés sans modification).

| Rôle BulkDirect | Agent Agency |
|---|---|
| Reddit Scout | marketing-reddit-community-builder, product-trend-researcher, product-feedback-synthesizer |
| Brainstorm | marketing-growth-hacker, sales-offer-lead-gen-strategist |
| Validator | testing-reality-checker, sales-pipeline-analyst, data-privacy-officer |
| Matcher | sales-outbound-strategist, sales-discovery-coach, supply-chain-strategist |
| Chef d'orchestre | agents-orchestrator |

Les 4 fichiers de `agents/` (reddit-scout, brainstorm, validator, matcher) restent les rôles du swarm. Les agents Agency s'ajoutent comme experts appelés par chaque rôle.
